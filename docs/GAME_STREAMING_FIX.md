# spark game：代码流式输出

**初始问题**：构建计划能逐 token 流式显示，进入写代码阶段却长时间像卡住；终端几乎看不到代码增长，左侧编辑器要么空白要么整文件突然出现，难以判断模型是否已在输出代码。

**根因**：计划走普通文本流；代码若走 `tool_call(write_file)`，内容在工具参数的 JSON 里成块传输，无法像正文那样平滑流式呈现。单文件体积过大时会进一步拉长单次可见间隔。

**做法**：不再用 `write_file` 输出代码；模型在**同一条文本流**里按 `FILE: 相对路径` + Markdown 代码块依次写多文件（保留 `read_file` 读盘）。CLI 边收流边解析，代码块未闭合前把内容当草稿推给编辑器，闭合后原子写盘。

**涉及**：`src/app/api/game/route.ts`、`src/lib/game/prompts.ts`、`cli/src/chat.ts`。

**说明**：上游/SDK 仍可能按块下发，体验会好于工具参数字节流，但不一定达到字符级「打字机」效果。
