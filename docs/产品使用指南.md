# QueryMind 产品使用指南

## 一、产品简介

QueryMind 是一款 AI 数据查询助手，让你用自然语言（说人话）查询数据库，无需学习 SQL。AI 自动生成查询语句、执行分析、智能选择最佳可视化方式展示结果。

## 二、核心功能

### 1. 自然语言查询
直接输入中文问题即可查询数据：
- "显示所有员工信息"
- "各部门平均薪资是多少"
- "上个月销售额最高的产品"

### 2. 智能可视化
AI 自动选择最合适的展示方式：
- 数据列表 → 表格
- 趋势对比 → 折线图
- 数值对比 → 柱状图
- 占比分布 → 饼图

### 3. 知识库问答
除了查询数据，还可以问知识性问题：
- "公司报销制度是什么"
- "请假流程怎么走"
- "绩效考核标准"

### 4. 快捷提问
侧边栏预设了 12 个常用问题，点击即可直接查询，适合新用户快速上手。

## 三、使用方法

### 基础查询
1. 在输入框输入你想查询的数据
2. 点击"发送"按钮或按 Enter
3. 等待 AI 返回结果（通常 2-5 秒）
4. 结果以表格或图表形式展示

### 查看 SQL
每次查询结果下方都有"查看 SQL"按钮，点击可以看到 AI 生成的 SQL 语句，方便学习和验证。

### 上传文档
1. 点击侧边栏底部的"上传知识文档"按钮
2. 选择 .txt 或 .md 格式的文件
3. 系统自动解析并存入知识库
4. 之后就可以问文档相关的问题了

## 四、使用限制

- 每分钟最多 10 次查询
- 单条消息最长 500 字
- 每日有 token 使用上限
- 仅支持 SELECT 查询（只读，不会修改数据）

## 五、常见问题

**Q: 查询结果不准确怎么办？**
A: 尝试换一种说法描述你的问题。例如"各部门薪资对比"比"给我看看工资情况"更精确。

**Q: 支持哪些图表类型？**
A: 目前支持柱状图、折线图和饼图。AI 会根据问题语义自动选择。

**Q: 数据安全吗？**
A: 系统采用多层安全防护，只允许查询操作，无法执行删除、修改等破坏性操作。
