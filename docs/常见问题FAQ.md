# 常见问题 FAQ

## 数据查询类

**Q: 我可以查询哪些数据？**
A: 目前数据库包含 5 张表：部门信息（departments）、员工信息（employees）、产品信息（products）、销售记录（sales）、费用支出（expenses）。共约 94 条示例数据。

**Q: 为什么查询结果跟我预期不一样？**
A: 可能原因：
1. 问题描述不够精确，AI 理解有偏差。建议使用更具体的表述。
2. 数据库中确实没有你要查的数据。系统会提示"未找到相关数据"。
3. AI 选择了不合适的图表类型。你可以明确指定，如"用柱状图展示"。

**Q: 能查实时数据吗？**
A: 当前版本使用的是预置示例数据（内存 SQLite）。生产环境可对接企业实际数据库（MySQL/PostgreSQL）。

## 知识库类

**Q: 知识库支持哪些文件格式？**
A: 目前支持 .txt 和 .md（Markdown）格式，文件大小不超过 1MB。

**Q: 上传的文档会保存多久？**
A: 文档存储在云端向量数据库中，长期保存，除非手动删除。

**Q: 知识库搜索不到结果怎么办？**
A: 可能原因：
1. 知识库中还没有相关文档，需要先上传。
2. 问题表述与文档内容差异较大，换种说法试试。
3. 文档内容过短或信息量不足。

## 安全类

**Q: AI 会不会执行删除数据等危险操作？**
A: 不会。系统在代码层面强制只允许 SELECT（查询）操作，即使用户尝试通过 prompt injection 攻击，也无法执行 DROP、DELETE、UPDATE 等破坏性操作。

**Q: 我的查询记录会被保存吗？**
A: 当前版本不保存查询历史。对话内容仅在当前会话期间有效，刷新页面后清空。

**Q: API Key 安全吗？**
A: API Key 仅存储在服务端环境变量中，不会暴露给前端。同时系统有 IP 限流和每日用量上限，防止被恶意刷取。

## 技术类

**Q: 底层用的什么 AI 模型？**
A: 默认使用阿里云百炼（DashScope）的 DeepSeek v3.2 模型。可配置为 GPT-4o、通义千问等任何 OpenAI 兼容 API。

**Q: 响应为什么是逐字出现的？**
A: 这是流式传输（Streaming）技术。AI 模型生成内容是逐 token 输出的，通过流式传输可以让你更快看到响应，无需等待全部生成完毕。

**Q: 支持多轮对话吗？**
A: 支持。系统会将历史消息一起发送给 AI，AI 能理解上下文。但目前未做专门的多轮追问优化。
